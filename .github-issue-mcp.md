## Feature: MCP Server Interface for CLI Commands

### Description

Add MCP (Model Context Protocol) server functionality to expose `consult` CLI commands as MCP tools. This would allow AI agents to interact with the customer management and workflow automation features programmatically through the MCP interface, in addition to the existing CLI.

### Motivation

- **Agent Integration**: MCP tools provide a structured, typed interface for AI agents to interact with the `consult` system
- **Consistency**: Agents could use the same tools whether working through terminal commands or MCP calls
- **Type Safety**: MCP schemas provide validation and documentation for tool parameters
- **Ecosystem**: Aligns with the growing MCP ecosystem for agentic tooling

### Proposed Implementation

1. **Create MCP Server Module**: Add `agentic_consult/mcp_server.py`
2. **Expose Core Commands**: Wrap key CLI commands as MCP tools:
   - `init_customer` (wraps `consult customers init`)
   - `show_customer` (wraps `consult customers show`)
   - `refresh_customer` (wraps `consult customers refresh`)
   - `add_customer_note` (wraps `consult customers notes add`)
   - `list_customer_notes` (wraps `consult customers notes list`)
   - `scan_for_sensitive_data` (wraps `consult precommit`)
   - `backup_customer_data` (wraps `consult backup`)
3. **Package Structure**: Follow MCP packaging conventions for easy installation
4. **Documentation**: Update README.md and create MCP-specific docs

### Benefits

- Provides dual interface (CLI + MCP) for maximum flexibility
- Enables richer agent workflows with structured data exchange
- Maintains single source of truth in the CLI implementation
- Further positions this tool as a comprehensive solution for agent-assisted consulting workflows
